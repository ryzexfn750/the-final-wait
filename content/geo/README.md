# Midnight Wave geographic data

File: `timezones-simplified.geojson`
Source: [dejurin/simplified-timezone-boundaries](https://github.com/dejurin/simplified-timezone-boundaries), itself simplified from [evansiroky/timezone-boundary-builder](https://github.com/evansiroky/timezone-boundary-builder), based on OpenStreetMap contributors.

**Data licence: Open Database License (ODbL) 1.0.** Retain the original attribution and licence for the derivative data, including its public download/source link. The generator code is MIT; it does not supersede the ODbL obligations on the geographic database. Data is distributed unchanged except for whitespace and removal of unused properties. Dataset contains 406 simplified timezone polygons and may omit small islands and precision along boundaries.

Time zone geometry is approximate; local midnight calculations use IANA/Intl rules for November 19, 2026. No Rockstar platform unlock time is asserted. All data is served on this site's same origin to avoid cross-origin runtime dependencies.

We must periodically review source boundary versions, aliases and political/offset changes; do not present this as a legally authoritative map.
